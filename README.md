# Jak zacząć w VS Code / Claude Code

1. Rozpakuj to archiwum w folderze projektu.
2. Skopiuj pliki źródłowe standardu do `źródła/` (patrz `źródła/README.txt`).
3. Otwórz folder w VS Code z zainstalowanym Claude Code.
4. Claude Code automatycznie wczyta `CLAUDE.md` przy starcie sesji — będzie znał
   cały kontekst decyzji i stan prac bez potrzeby tłumaczenia od nowa.
5. Szczegóły uruchomienia skryptów: patrz sekcja "Jak odtworzyć / kontynuować"
   w CLAUDE.md.
